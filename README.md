# BizPilot AI Premium

A static, responsive business-management UI demo built with HTML, CSS and vanilla JavaScript.

## Pages
- Landing page
- Dashboard
- Invoices
- Expenses
- Customers
- Analytics
- AI Assistant

## Run
Open `index.html` locally or deploy the project folder to GitHub Pages. No build step is required.

## Notes
This is a front-end demo. Dashboard data and AI responses are simulated in JavaScript.
